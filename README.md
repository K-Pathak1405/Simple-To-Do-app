# 📝 To-Do App

A simple **To-Do App** built using **HTML and JavaScript**.

## ✨ Features

- 📋 Show all tasks
- ➕ Add a task
- 🗑️ Delete a task
- 🚪 Quit the app

## 🛠️ Technologies

- 🌐 HTML
- ⚡ JavaScript

## 🚀 How to Run

1. Clone or download the repository.
2. Open `index.html` in your browser.
3. Start managing your tasks.
